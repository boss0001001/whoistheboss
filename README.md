**whoistheboss**
A small Bash project I made while learning Linux, shell scripting, Git, and GitHub.

The script displays my S.R. name in the terminal using ASCII characters and green and white colors.

**HOW TO RUN**

Clone the repository:

git clone https://github.com/boss0001001/whoistheboss.git

Go into the folder:

cd whoistheboss

Make the script executable:

chmod +x whoistheboss

Run it:

./whoistheboss
